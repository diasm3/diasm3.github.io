# JavaScript의 기원과 발전

JavaScript는 웹 개발에서 중요한 역할을 하는 스크립팅 언어로, 그 기원은 다음과 같습니다.

1. **초기 개발 단계**  
Java -> Scheme 조합으로 시작했지만, 너무 복잡하여 쉽게 만들기 위해 Mocha라는 이름의 프로토타입이 개발되었습니다.  
Mocha는 이후 LiveScript로 변경되었으며, Java의 인기를 활용하기 위해 JavaScript라는 이름으로 바뀌었습니다.

2. **Microsoft의 JScript**  
마이크로소프트가 JavaScript를 모방하여 JScript를 개발하였고, 두 언어는 많은 차이를 보였습니다.

3. **ECMAScript의 탄생**  
JavaScript의 문법적 규칙을 정의하기 위해 1997년 ECMAScript 1이 발표되었습니다. 이 시기에 Internet Explorer는 95%의 시장 점유율을 기록하며 주요 브라우저로 자리 잡았습니다.

4. **AJAX의 등장**  
2000년대 초반부터 AJAX를 통해 비동기 처리 기능이 추가되었습니다. 다양한 브라우저에 대응하기 위해 다양한 라이브러리(JQuery, Dojo 등)가 개발되었습니다.

5. **JIT 컴파일과 ECMAScript 발전**  
2008년 Chrome 브라우저에서 JIT(Just-in-Time) 컴파일이 도입되었습니다. 이후 2009년에 ECMAScript 5가, 2015년에 ECMAScript 6가 발표되었습니다.

6. **주요 JavaScript 엔진**  
   - Chrome - V8  
   - Firefox - SpiderMonkey  
   - Safari - JSCore  
   - MS Edge - Chakra (현재 V8 사용)  
   - Opera - Carakan  
   - Adobe Flash - Tamarin

7. **트랜스 컴파일러인 Babel**  
Babel은 최신 JavaScript 문법을 구버전 브라우저에서도 사용할 수 있도록 변환해주는 트랜스 컴파일러입니다.

8. **Single Page Application (SPA)**  
React, Angular, Vue와 같은 프레임워크를 통해 SPA가 가능해졌으며, 이는 웹 애플리케이션의 발전을 이끌었습니다.

9. **백엔드 및 모바일 통합**  
JavaScript는 이제 백엔드와 모바일 애플리케이션 개발에도 활용되고 있으며, WebAssembly와 같은 기술을 통해 더욱 확장 가능해졌습니다.
