# 미니프로젝트: 칵테일 웹 애플리케이션

이 문서는 제가 참여했던 첫 번째 프로젝트에 대한 기록입니다. 칵테일 웹 애플리케이션을 개발하며 느낀 점을 공유하려고 합니다.

이 프로젝트는 저뿐만 아니라 다른 팀원들에게도 힘든 도전이었습니다. 사용한 기술 스택은 Python, Flask, 그리고 API 통신이었으며, 처음 Python을 사용해 보는 저에게 많은 도전이 있었습니다. 

처음에 프로젝트를 진행할 때, Python의 기본 사용법을 이해하는 데 어려움이 많았습니다. 결국 프로젝트의 마지막에는 코드가 어떻게 작동하는지 조금씩 이해하게 되었지만, 아쉽게도 프로젝트를 완전히 마무리하지는 못했습니다.

팀의 다른 두 명의 개발자가 열심히 작업했지만, 최종 제품을 완성하는 데에는 어려움이 있었습니다. 저 또한 협업을 처음 해보는 것이었기에, 각자 만들어 온 부분을 통합하는 데에 어려움을 겪었습니다. Git의 역할을 당시 충분히 활용하진 못했던 것 같아 아쉬움이 남습니다.

결과적으로, 비록 실패했다고 느끼긴 했지만, Python으로 프론트엔드와 백엔드를 모두 다루어 보았던 경험은 저에게 매우 값진 시간이었습니다.
