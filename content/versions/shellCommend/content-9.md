# 자주 잊어버리는 쉘 명령어 모음

이 문서는 일상에서 자주 사용하지만 잊어버리기 쉬운 쉘 명령어 모음을 제공합니다. 각 명령어는 간단한 설명과 예제를 포함하고 있습니다.

## 1. 로컬에서 서버로 복사 붙여넣기

- 명령어: `scp`
- 설명: 원격 서버에 파일을 안전하게 복사하는 명령어입니다. `-P` 옵션을 통해 포트 번호를 지정할 수 있습니다.

```bash
scp -P 1600 ~/dev/hello user@myserveripaddress:/usr/share/nginx/html
```

## 2. 파일 찾기

- 명령어: `find`
- 설명: 지정된 디렉토리에서 특정 파일을 찾는 명령어입니다.

```bash
find /path/to/search -name "filename.ext"
```

### 3. 기타 유용한 명령어

- `grep`: 텍스트 파일에서 정규 표현식에 맞는 문자열을 검색합니다.

### 사용 예시
- `scp` 명령어를 사용하여 웹 서버에 HTML 파일을 업로드할 때 유용합니다.
- `find` 명령어는 대규모 파일 시스템에서 필요한 파일을 빠르게 찾을 수 있게 해줍니다.
