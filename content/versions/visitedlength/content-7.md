# 문제 설명
> 이 문제는 이동 경로를 바탕으로 얼마나 많은 길을 방문했는지를 계산하는 문제입니다.

# 문제풀이 
> 2022-03-24 21:37:09 풀었던 문제이다.

1. 올바른 방향으로 진행은 했다.
2. 결과값을 카운팅하는 부분에서 막혔다.
3. 처음에는 2차원 배열로 같은 방향으로 진행되는 부분을 없애려고 했으나, SET 사용이 어려웠다.
4. 일반 배열의 SET은 그냥 사용하면 되었는데, 2차원 배열의 SET은 좀 어려웠다.
5. 해결 방법은 문자열로 4자리 수로 변경하여 앞 두 자리는 기존 좌표, 나머지 좌표는 다음 좌표로 설정했다.
   * 예제: 5554 -> (5,5)에서 (5,4)로 Y축 -1 만큼 이동
   * [5554, 5444, ...] 이것을 SET으로 돌리면 같은 값은 없어진다.
6. 그런데 간과한 게 양방향으로 같을 경우를 생각하지 못했다....

## 추가 설명
> 기존에 갔던 길은 카운터를 안 하는 게 중요한 문제이다.

## 코드 예시
```python

def solution(dirs):
    # 좌표값을 설정한다. 위 아래 좌우로 이동할 때 X축과 Y축을 정의한다.
    moving = {
        "L" : (-1, 0), # 왼쪽으로 한 칸 가기
        "R" : (1, 0),   # 오른쪽으로 한 칸 가기
        "U" : (0, 1),  # 위로 한 칸 가기
        "D" : (0, -1), # 아래로 한 칸 가기
    }
    
    group = []
    cnt = 0 
    x, y = 5, 5
    
    for i in dirs:
        # 이동 후 좌표를 업데이트
        x += moving[i][0]
        y += moving[i][1]
        # 유효한 범위를 벗어나지 않도록 좌표 제한
        x = max(0, min(x, 10))
        y = max(0, min(y, 10))
        # 이전 좌표를 담아 현재 이동 경로를 체크
        group.append((x, y))
    
    return len(set(group))  # 중복 경로를 제거한 후 길이 반환
```
