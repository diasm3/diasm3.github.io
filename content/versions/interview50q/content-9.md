# 인터뷰 준비를 위한 예상 질문 50문제
> 항해측에서 제공하는 기본 50문제입니다. 각 문제를 통해 면접 준비를 더욱 철저히 하세요.

## 1. var, let, const는 어떻게 다른가요?
- **var**: 동일한 이름으로 변수 선언 시 에러가 발생하지 않으며, 코드량이 많아지면 오류를 찾기 어려움.
- **let**: 동일 이름으로 변수 선언 시 에러가 발생하며, 변수 재할당이 가능함.
- **const**: 변수 재할당이 불가능하지만, 객체의 속성은 변경 가능함 (객체의 주소값은 변경할 수 없음).

## 2. Event Loop란 무엇인가요?
- Event Loop는 JavaScript의 비동기 처리 모델로, 콜백 함수를 대기시키고 이벤트를 처리하는 메커니즘을 의미합니다.

## 3. Express의 역할은 무엇인가요?
- Express는 Node.js의 웹 애플리케이션 프레임워크로, 라우팅, 미들웨어 설정 등을 통해 서버 구축을 단순화합니다.
  * npm과 yarn 각각에 대해 설명해주세요
    - **npm**: 패키지 설치 속도가 느리지만, 패키지 종속성을 관리합니다.
    - **yarn**: 병렬로 패키지를 설치하여 속도가 빠르며, 항상 `yarn.lock` 파일을 통해 버전을 관리합니다. 보안성이 우수합니다.

## 4. Event-driven programming에 대해 아시나요?
- 이벤트 기반 프로그래밍은 프로그램의 흐름이 이벤트에 따라 결정되는 방식입니다.

## 5. Promise에 대해 아시나요?
- Promise는 JavaScript의 비동기 프로그래밍을 다루는 객체로, 비동기 작업의 완료 또는 실패를 나타냅니다.

## 6. Node.js의 장단점을 설명해주세요.
- 장점: 비동기 I/O, 높은 성능, 대규모 애플리케이션에 유리.
- 단점: CPU 집약적 작업에 불리.

## 7. 콜백 지옥 해결 방안에 대해 아는 대로 설명해주세요.
- Promise 및 async/await 사용으로 콜백의 중첩을 줄이고, 가독성을 향상시킬 수 있습니다.

## 8. Single Threaded Async가 무슨 뜻인지 아시나요?
- 단일 스레드에서 비동기 작업을 수행하여 다수의 작업을 처리할 수 있음을 의미합니다.

## 9. 비동기 처리 Promise와 async/await의 차이에 대해 설명해주세요.
- Promise는 비동기 결과를 처리하는 객체이며, async/await 구문은 Promise의 사용을 더 간편하게 만들어 줍니다.

## 10. REST API에 대해 설명해주세요.
- REST API는 HTTP 프로토콜을 사용하여 자원에 대한 상태를 주고받는 아키텍처 스타일입니다.

## 11. OOP에 대해 설명해주세요.
- 객체 지향 프로그래밍(OOP)은 데이터와 행동을 객체로 묶어 나타내는 프로그래밍 패러다임입니다.

## 12. GET과 POST는 어떻게 다른가요?
- **GET**: 서버에서 데이터를 요청할 때 사용되며, URL에 데이터가 포함됨.
- **POST**: 서버에 데이터를 전송할 때 사용되며, 요청 본문에 데이터가 포함됨.

## 13. Node.js를 사용해야 하는 이유가 있나요?
- 비동기 처리, 크로스 플랫폼, 빠른 성능 때문입니다.

## 14. Node.js의 동작 원리를 설명해주세요.
- 이벤트 기반, 논블로킹 I/O 모델로 동작하여 비동기 처리를 수행합니다.

## 15. I/O 논블로킹에 대해 아는 대로 설명해주세요.
- I/O 작업이 완료될 때까지 다른 작업을 진행할 수 있는 방식을 의미합니다.

## 16. 웹 서버란 무엇인가요? WAS와 WS가 어떻게 다른가요?
- 웹 서버는 클라이언트 요청에 대한 응답을 제공하는 서버이며, WAS는 웹 애플리케이션 서버로, 동적 콘텐츠 처리를 담당합니다.

## 17. Node.js에서 fork()와 spawn() 메소드의 차이는 무엇인가요?
- **fork()**: 자식 프로세스를 생성하여 동일한 코드 실행.
- **spawn()**: 새로운 프로세스를 생성하고 명령어를 실행.

## 18. 실행 컨텍스트에 대해 아는 대로 설명해주세요.
- 실행 컨텍스트는 코드가 실행되는 환경으로, 변수, 함수의 스코프 등이 정의됩니다.

## 19. 콜백 함수란 무엇인가요?
- 다른 함수에 인자로 전달되어 실행되는 함수를 의미합니다.

## 20. axios를 사용해본 경험이 있나요?
- Axios는 HTTP 요청을 위해 주로 사용되는 Promise 기반 라이브러리입니다.

## 21. 호이스팅이 무엇인지 설명해주세요.
- 변수와 함수 선언문이 그 범위 내 최상단으로 끌어올려지는 현상을 의미합니다.

## 22. 클로저에 대해 설명해주세요.
- 클로저는 함수가 내부 변수에 접근할 수 있는 특성을 가지며, 외부 함수의 실행 컨텍스트와 결합됩니다.

## 23. WAS(nginx)는 어떤 이유로 사용하나요?
- 웹 애플리케이션 서버로써 높은 성능과 동시 접속 처리를 위한 분산 로드 밸런싱을 제공합니다.

## 24. _proto_를 아시나요? 어떻게 사용하는지 설명해주세요?
- 프로토타입 체인을 통해 상속을 구현하고 객체의 속성에 접근하기 위해 사용됩니다.

## 25. 동기와 비동기의 차이는 무엇인가요?
- **동기**: 작업을 순차적으로 진행.
- **비동기**: 작업이 완료될 때까지 기다리지 않고 다른 작업을 진행.

## 26. package.json이 꼭 필요한가요?
- Node.js 프로젝트의 메타데이터, 의존성, 스크립트 등을 관리하기 위해 필요합니다.

## 27. CORS가 무엇인가요?
- 다른 도메인에서 리소스에 접근하는 것을 제어하는 보안 메커니즘입니다.

## 28. npm를 사용하는 이유는?
- 패키지를 쉽게 관리하고, 의존성을 자동으로 해결할 수 있습니다.

## 29. XSS 공격에 대해 아시나요?
- 사용자 입력을 통해 악성 스크립트가 실행되는 공격입니다.

## 30. Git을 사용해 협업한 경험이 있나요? 어떻게 사용했나요?
- 버전 관리를 통해 협업 중 발생할 수 있는 충돌을 최소화하며 진행하였습니다.

## 31. ORM을 사용해본 적이 있나요?
- ORM은 데이터베이스 접근을 객체 지향적으로 처리하여 SQL 사용을 최소화합니다.

## 32. this의 용법에 대해 아는 대로 설명해주세요.
- 함수를 호출한 객체를 가리키며, 자바스크립트에서는 유동적입니다.

## 33. 무한 스크롤을 구현해본 적이 있나요? 방법은?
- 스크롤 시 데이터를 추가로 요청하여 클라이언트에 소트를 업데이트합니다.

## 34. JWT에 대해 설명해주세요.
- JSON 웹 토큰으로, 정보 교환을 안전하게 해주는 인코딩된 문자열입니다.

## 35. Oauth에 대해 설명해주세요.
- 사용자 인증과 인가를 위한 개방형 표준 프로토콜입니다.

## 36. 미들웨어의 역할이 무엇인가요?
- 요청과 응답 사이에서 기능을 수행하며, 라우팅을 쉽게 구현할 수 있게 도와줍니다.

## 37. moment.js를 사용하였다면 어떻게 사용하였는지, 그리고 그 이유는?
- 날짜와 시간을 관리하기 용이하도록 다양한 기능을 제공하는 라이브러리입니다.

## 38. super, prototype에 대해 아시는 것이 있다면 이야기해주세요.
- **super**: 부모 클래스의 메서드 호출 및 속성 접근을 가능하게 합니다.
- **prototype**: 객체의 공유된 속성과 메서드를 정의합니다.

## 39. 스택과 큐에 대해 설명해주세요.
- **스택**: 후입선출(Last In First Out) 구조.
- **큐**: 선입선출(First In First Out) 구조.

## 40. 힙에 대해 아는 것이 있다면 얘기해주세요.
- 메모리 관리의 한 방식으로, 동적으로 할당된 메모리를 관리합니다.

## 41. 알고 있는 정렬의 종류에 대해 설명해주세요.
- 버블 정렬, 선택 정렬, 삽입 정렬, 퀵 정렬 등 다양한 정렬 기법이 있습니다.

## 42. 데이터에 대한 연산을 DB 내에서 하는 게 좋을까요? 서버에서 하는 게 좋을까요?
- 데이터 양과 연산 복잡도에 따라 결정되지만, 일반적으로 DB 내에서 연산을 수행하는 것이 효율적입니다.

## 43. 세션과 쿠키에 대해 설명해주세요.
- **세션**: 서버에 저장되는 사용자 정보를 나타내며, 주로 로그인 상태를 유지하기 위해 사용됩니다.
- **쿠키**: 클라이언트에 저장되고, 사용자의 설정 등을 기록하는 데 사용됩니다.

## 44. Array.length의 시간 복잡도는 몇일까요?
- O(1) - 배열의 길이는 상수 시간에 접근할 수 있습니다.

## 45. setTimeout 함수를 실행했을 때 일어나는 과정에 대해 얘기해주세요.
- 일정 시간 후에 등록된 콜백을 실행합니다. 이벤트 큐에 추가되어 실행됩니다.

## 46. 주소창에 naver.com을 쳤을 때 일어나는 과정을 설명해 주세요.
- 도메인 해석, DNS 쿼리, 서버 요청 및 응답 과정을 거쳐 페이지가 로드됩니다.

## 47. TCP와 UDP의 차이에 대해 알려주세요.
- **TCP**: 연결 지향, 데이터 전송 순서 보장.
- **UDP**: 비연결형, 속도가 빠르지만 데이터 전송 순서 보장하지 않음.
