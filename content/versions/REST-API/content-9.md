# REST API란?
> REST(Representational State Transfer)는 네트워크를 통해 컴퓨터 간의 통신을 가능하게 하는 아키텍처 스타일이다. 이 API는 HTTP 프로토콜을 기반으로 하여 자원의 상태를 전송한다.

## API란?
> API(Application Programming Interface)는 운영체제와 상관없이 소프트웨어 구성 요소 간에 데이터를 주고받는데 필요한 인터페이스를 정의한다.

### API의 유형
1. Private API: 내부 시스템과 애플리케이션에서 사용되는 API
2. Public API: 모든 개발자가 자유롭게 사용할 수 있는 API
3. Partner API: 특정 파트너나 기업에 의해 제한된 접근 권한을 가진 API

## 실제 사용 사례
REST API는 다양한 웹 서비스와 모바일 애플리케이션에서 활용되며, 구체적인 예시로는:
- 트위터 API: 사용자가 트윗을 주고받고 검색할 수 있도록 지원
- 구글 지도 API: 사용자 위치 기반 정보 제공 및 지도 기능 구현
