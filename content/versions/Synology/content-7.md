# About Synology
Synology is a Network Attached Storage (NAS) solution that provides significant functionality for both home and business users.

## Features
1. Centralized data storage.
2. Easy integration with Time Machine for backups.
3. Ability to add custom applications using Docker.
4. Remote access capabilities.
