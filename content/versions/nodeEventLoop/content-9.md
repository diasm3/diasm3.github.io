# 이벤트 루프란?
> 이벤트 루프는 Node.js를 통해 논블로킹 I/O 가능성을 제공하는 메커니즘입니다. 자바스크립트는 싱글 스레드로 작동하기 때문에 이 구조가 중요합니다.

최신 운영체제 커널들은 멀티 스레드를 지원하고, 백그라운드에서 여러 개의 스레드를 관리할 수 있습니다. 작업이 완료되면, 커널은 Node.js에게 해당 작업이 완료되었다고 콜백을 전달하고, Poll 큐에 등록 후 실행됩니다.

- 비동기(asynchronous): 두 가지 작업이 동시에 시작하지 않는 경우
- 동기(synchronous): 두 가지 작업이 동시에 시작하는 경우

## 이벤트 루프의 작동 원리
Node.js가 시작되면 이벤트 루프가 초기화되고, 프로세스는 입력 스크립트로 비동기 작업을 처리합니다.

### 이벤트 루프 단계
1. **타이머**: 정해진 시간 후에 콜백을 실행합니다.
2. **I/O 콜백**: 비동기 작업이 완료되면 호출됩니다.
3. **idle, prepare**: 내부용도로 사용됩니다.
4. **poll**: 비동기 I/O 작업을 처리합니다.
5. **check**: `setImmediate()`에 의해 예약된 콜백을 실행합니다.
6. **close**: 소켓과 같은 자원이 닫혔을 때 호출됩니다.

### 예제 코드
다음은 간단한 이벤트 루프의 예시입니다:

```javascript
console.log('시작');

setTimeout(() => {
    console.log('타이머');
}, 0);

Promise.resolve().then(() => {
    console.log('프로미스');
});

console.log('끝');
```

### 실제 사용 사례
이벤트 루프는 웹서버와 같은 어플리케이션의 핵심으로, 비동기 I/O를 통해 높은 처리량과 응답성을 제공합니다.
