# Tmux 개요
Tmux는 터미널 멀티플렉서로 여러 세션을 동시에 실행하고 관리할 수 있는 도구입니다. 여러 작업을 동시에 진행해야 할 때 매우 유용합니다.

## 설치 방법
가장 최신 버전의 Tmux를 설치하기 위해서는 다음 명령어를 사용하십시오:
```bash
sudo apt-get install tmux
```

## 기본 사용법
### 세션 시작
Tmux 세션을 시작하려면 다음 명령어를 입력하세요:
```bash
tmux
```

### 세션 분할
세션을 수직으로 분할하려면 다음 단축키를 사용하십시오: 
```
Ctrl-b %
```

## 유용한 명령어
- `tmux ls`: 현재 실행 중인 세션 목록
- `tmux attach -t [세션 이름]`: 지정한 세션에 연결
